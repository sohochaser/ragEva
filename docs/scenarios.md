# 场景评价标准与预览

US-010 提供三个按场景保存的评价标准：忠实度、相关性、正确性。新建场景产生版本 1；每次修改生成不可变新版本。场景列表返回最新版，版本接口返回全部历史版本。固定系统提示词、变量和输出形状由 `GET /api/v1/scenarios/template` 只读提供，当前版本为 `answer-eval-v1`。

在线评分模型通过 `POST /api/v1/online-models` 配置，`base_url` 指向兼容 OpenAI Chat Completions 的 API 根路径（通常以 `/v1` 结尾），另填模型名和可选 Bearer Token。Token 独立存于数据目录的 `secrets/models/`，文件权限为 `0600`，API 响应不返回密钥。预览调用 `/chat/completions`，固定温度为 0，请求 JSON 对象响应；本系统校验 `score` 为 0 到 1 的有限数字且 `reason` 为非空字符串。模型响应格式不符合契约时返回诊断错误，不修改已保存场景。

单题预览需提供问题、预测答案、标准答案和至少一条上下文；分别使用所选场景版本的三项标准。预览结果包含逐项分数、原因、原始模型响应和接口实际报告的输入/输出 token。预览不写入正式评测运行。实际回答质量批量评分属于 US-011。
