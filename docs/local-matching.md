# 本地向量匹配预览（US-005）

匹配预览使用 [FastEmbed](https://qdrant.github.io/fastembed/) 的本地 ONNX 推理。默认模型为 `BAAI/bge-small-zh-v1.5`；首次使用时从模型源下载权重到数据目录的 `models/`，之后可勾选“仅使用本地文件”离线加载，也可指定已有模型目录。模型目录必须与所填模型名称兼容。运行检索路径不请求 SaaS 向量服务或生成式模型。

在“预测批次”中选择一条有参考及预测 chunk 的样本后，可填写本地模型、模型专属相似度阈值并预览。切换模型或模型目录会清空阈值，需要针对新模型重新填写；建议用代表性样本观察命中与误匹配，再固定运行配置。默认中文模型的初始值 `0.8` 只用于开始校准，不表示通用阈值。

接口 `POST /api/v1/matching/preview` 返回每对参考/预测 chunk 的原始位置、余弦相似度、是否达到阈值，以及 `candidate`、`below_threshold`、`document_mismatch` 原因；同时返回 K=10/20 的一对一配对、Precision、AP、NDCG 和规则版本。文档 ID 不同的组合不计算相似度；同一文档 ID 本身不算命中。预测批次可在“评测运行”页异步评分，运行级 MAP 是有效题目 AP 的均值，逐题证据保存在运行结果中。

向量缓存在数据目录的 `embeddings.sqlite3`，键由模型权重内容指纹和 chunk 正文确定。相同模型及正文复用向量；更换权重会产生新的模型指纹，更换阈值只重新判定候选边。权重下载、离线目录、模型兼容性或编码失败会给出错误，不会以文档 ID 相同伪造候选命中。
