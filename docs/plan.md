# 实施任务拆解草案

每一阶段以前一阶段的可运行验收产物为入口。

| 阶段 | 交付物 | 验收重点 |
| --- | --- | --- |
| 0. 需求基线 | 确认目标协议、样本规模、部署与评测模型约束 | 用户流程与接口输入输出可验收 |
| 1. 工程 Harness | 前后端骨架、容器环境、CI、测试命令、OpenAPI、Agent 入口 | 新克隆仓库可一条命令启动和测试 |
| 2. 数据集与目标 | 数据集版本、导入校验、目标配置和连接测试 | 错误行可定位；密钥不回传 |
| 3. 运行与评测 | 异步执行、状态机、指标、逐样本证据 | 失败/取消/重试可复现；分数可解释 |
| 4. 前端工作流 | 导入、配置、运行、详情、比较、导出 | 浏览器 E2E 覆盖主路径 |
| 5. 稳定性与交付 | 完整回归、性能与故障验证、部署文档 | CI 全绿，前后端契约与主要运行场景通过 |

每项任务的完成定义：验收条件可运行、自动化检查通过、文档与契约同步、GitHub 上可追踪提交。
